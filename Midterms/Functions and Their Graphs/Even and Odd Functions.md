"Even" and "Odd" describes the symmetery of a function. 

# Even
Functions that are even are symmetrical in the y-axis. If you mirror them horizontally, it will still produce the same image.

Therefore, function f(x) is even if f(x) = f(-x)

# Odd
Functions that are odd are symmetrical at their origin. In simpler terms, even if you flip them upside-down they remain the same.

Therefore, function f(x) is odd if -f(x) = f(-x)

# Examples

![Quad](https://dr282zn36sxxg.cloudfront.net/datastreams/f-d%3A7b4fdd6fe48cfa78fcdc3cd594b325ca5520460b6da6702086b3051e%2BIMAGE_THUMB_POSTCARD_TINY%2BIMAGE_THUMB_POSTCARD_TINY.1)

in the function f(x) = x^2, f(x) is even since:
f(x) = x^2 
f(-x) = (-x)^2 = f(-x) = x^2 
-f(x) = -(x^2)
f(x) = f(-x)

![cube](https://dr282zn36sxxg.cloudfront.net/datastreams/f-d%3A0e8b717435a019ca8d0538ced7adee75b2ab00cc907251eae05d293c%2BIMAGE_THUMB_POSTCARD_TINY%2BIMAGE_THUMB_POSTCARD_TINY.1)

in the function f(x) = x^3, f(x) is odd since:
f(x) = x^3 
f(-x) = -(x^3)
-f(x) = -(x^3)
f(-x) = -f(x)
