# What is a function?
A function, in mathematics, an expression, rule, or law that defines a relationship between one variable (the independent variable) and another variable (the dependent variable). 
[Source](https://www.britannica.com/science/function-mathematics)

**Think of a function as a factory:**
Some number goes in (often 'x')
Some process happens to change the input
A changed number goes out (often 'y')

The number going in can only put out one changed number. You can't have 'x' outputting both a one and a three, but you can have 'B' and 'C' output six.
